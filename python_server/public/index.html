📖 网络请求接口 (Serverless API)

你可以直接将本服务作为公共 API 嵌入到 QQ 机器人、Discord 机器人、Markdown 文档或网页中。

1. 直接图片 GET 直链（最适合在 Markdown、HTML 或聊天工具中引用）

无需发 POST 请求，直接访问 URL 即可输出原始图片流：

GET /api/generate?pack=pjsk&sticker=Airi%2001&text=something&format=png

2. Markdown 嵌入语法

![Meme](http://localhost:3000/api/generate?pack=pjsk&sticker=Airi%2001&text=something)

3. JSON POST 请求接口（适合前端或后端程序调用）

Endpoint: POST /api/generate

curl -X POST http://localhost:3000/api/generate \
  -H "Content-Type: application/json" \
  -d '{
    "pack_slug": "pjsk",
    "sticker_name": "Airi 01",
    "text": "something",
    "font_size": 46,
    "text_x": 148,
    "text_y": 58,
    "text_rotate_degrees": -11.5,
    "text_color": [251, 138, 172, 255],
    "stroke_color": [255, 255, 255, 255],
    "stroke_width_factor": 0.23,
    "auto_resize": true,
    "image_format": "png"
  }'

4. 获取所有可用贴纸清单

Endpoint: GET /api/packs

返回所有已加载贴纸包的分类与贴纸元数据（包含默认文本坐标、角度、颜色配置）。
